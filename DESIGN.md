# AGY Video Studio: Default Design & Brand Direction (Option A)

Reading this as: Multi-profile local open-source video studio combining WeftCut MCP timeline editing, OneTake continuous-take motion films, HyperFrames GSAP/Three.js compositions, and audio-first clipping/SFX skills, dial `ENERGY 2 / RHYTHM 3 / MOTION 3`.

## 1. Anti-Slop Dials (Default Studio Baseline)
- **ENERGY: 2 (Balanced-to-Bold):** Clean visual hierarchy and purposeful typography without neon or rainbow clutter.
- **RHYTHM: 3 (Varied & Asymmetric):** Every beat varies in duration, framing, and density. Uniform slide-show cadence is rejected by OneTake's `probe.py` / `verify_promo.py`.
- **MOTION: 3 (Choreographed & Continuous):** Elements carry across beat boundaries using measured `studio_kit/motion_primitives.js`, OneTake springs (`lib/motion.js`), GSAP timelines (`hyperframes`), Three.js `r186` scenes, or WeftCut bezier keyframes and Motifs rather than generic fade-up template loops.

## 2. Core Palette, Stage & Mixed-Voice Typography Rules (One-Line Reasons per R-31)
- **Base Surface (`#0B0F17` Deep Carbon / `#F8FAFC` Editorial Paper):** Provides high-contrast ground (>12:1 WCAG AAA against primary text) plus warm/cool ambient radial lighting and subtle vignette so text feels embedded in the frame instead of floating on a flat black web page.
- **Primary Text (`#F8FAFC` on Dark / `#0F172A` on Light):** Ensures instant legibility during fast camera moves.
- **Muted Technical Metadata (`#94A3B8`):** Separates secondary captions and labels from primary headlines while keeping contrast >= 4.6:1.
- **Single Deliberate Accent (Project-Scoped):** Reserved strictly for the active focal point or split-color punch glyph of each beat (R-29).
- **Mandatory Bundled Fonts (`@font-face` + Mixed-Voice Typography):** Windows lacks `Plus Jakarta Sans`, `Inter`, and `Montserrat` system-wide, so unbundled stacks fall back to `Segoe UI` and look like web dialogs. Every composition and Motif MUST load self-hosted fonts from `studio_kit/fonts/` via `@font-face` and await `document.fonts.load(...)`. Pair Mixed-Voice contrast cleanly: tight bold geometric sans (`Inter Tight` 800, `-0.04em` tracking) + italic editorial serif (`Instrument Serif` / `Fraunces` italic, normalized via `font-size-adjust: from-font` with `@supports not` fallback) + tabular monospace (`JetBrains Mono` / `Geist Mono`) strictly for telemetry (R-06).

## 3. Style Profiles & Skill Routing
1. **`mograph-pro` (OneTake / HyperFrames / Three.js r186 / Barty-Bart Explainers - ENERGY 2 / RHYTHM 3 / MOTION 3):** Continuous camera carry, captured/rebuilt real UI (`record_footage.py` / `npx hyperframes capture`), 180-360 degree shutter motion blur, Three.js `r186` 3D scenes, `studio_kit/motion_primitives.js`, and beat-measured SFX (`sound-effects` / `scripts/sfx_palette.py`).
2. **`gaming-montage` (Faide Reference via WeftCut MCP + `ffmpeg-skill` + `librosa` - ENERGY 3 / RHYTHM 3 / MOTION 3):** Beat-synced cuts (`librosa` onsets), velocity speed-ramps, zero sticker clutter, ultra-brief 1-2 word callouts (`rolling-cylinder-slot` or decode hit), and crisp transient audio hits on WeftCut's SFX role track.
3. **`gaming-comedic` (Windah / MILYHYA Reference via WeftCut MCP + `claude-shorts` + `object-separation` - ENERGY 3 / RHYTHM 3 / MOTION 2):** Audio-first cut-and-play (`detect_pauses` / `remove_pauses` / `claude-shorts` boundary snapping), sudden music cut-outs (`set_role_gain` / keyframed music mute) before punchlines, expressive snap-zooms, optional subject cutout for text-behind-subject (`1s-3s` hook clips), and word/letter-level WeftCut Motifs (`ghost-echo-kinetic` / `apple-follower-reveal`).
4. **`talking-head-reel` (`ghost-editor` 19 Visual Styles + `motion-video-director` Free Audio Override - ENERGY 2 / RHYTHM 3 / MOTION 2):** Clean OS, Kinetic doc, Swiss Grid, Halftone Dossier, or Telestrator blueprints using `apple-follower-reveal` per-glyph stagger, `ghost-echo-kinetic`, and `kinetic.mjs` rendered locally on Windows with original speaker audio or free local audio.

## 4. Calibrated Motion, Text & Transition Craft Baseline (`studio_kit/`)
- **Transitions (`references/transitions_study/TRANSITIONS_GUIDE.md`):** Prefer physical or optical transitions over hard fades: 3-layer foreground occlusion wipes (`XLMHpphSxJQ`), 5-8 frame cutout frame-hold slide-ins with directional blur (`wkbAl3Y2DnM`), smooth bezier mask reveals peaking at 50% velocity (`rK6t1utoWrc`), and 25-45 degree feathered split wipes with subtle counter-zoom (`ruwVARuOkqA`).
- **Text Motion & Anti-Web-Box Mandate (`references/text_motion_study/TEXT_MOTION_GUIDE.md`):** Never slap flat full-block fade/scale boxes onto hero footage. Use `studio_kit/motion_primitives.js` and `studio_kit/motifs/` (`apple-follower-reveal`, `ghost-echo-kinetic`, `rolling-cylinder-slot`, `kinetic-3d-spatial`) alongside `hyperframes-registry` (`motion-blur`, `slot-machine-roll`, `caption-parallax-layers`, `text-match-cut`) and `ghost-editor/scripts/lib/kinetic.mjs`.
- **Shutter Blur & Visual Proof:** Fast horizontal/vertical text travel or wipes must carry real sub-frame shutter blur (`180-360` deg in HyperFrames/OneTake) or directional SVG blur, and every completed sequence MUST pass a mid-motion contact-sheet inspection with `read_file` before final handoff.
